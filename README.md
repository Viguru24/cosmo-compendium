# Cosmo Compendium (Heirloom Recipes)

An exquisite, heirloom cookbook and kitchen assistant for Android, featuring AI-assisted recipe parsing, culinary conversions, realistic leather booklet aesthetics, and multi-device sync.

## Sovereign Over-The-Air (OTA) Updates
This app is equipped with independent sovereign Over-The-Air updates served directly from `https://api.cosmowhisper.com/updates/cosmo-compendium`.

- **Automatic Check:** Checks for updates silently upon launch.
- **Manual Check:** Available in Settings under **Sovereign Over-The-Air (OTA) Updates**.
- **One-Click Deployment:** Run `.\publish-update.ps1` or double-click `PUBLISH_UPDATE.bat` (or use the Desktop launcher) to publish a new APK to the sovereign VPS in seconds.

For full architectural details, see [OTA_UPDATE_GUIDE.md](OTA_UPDATE_GUIDE.md).
